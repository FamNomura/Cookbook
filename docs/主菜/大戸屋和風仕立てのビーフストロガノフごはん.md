# 大戸屋和風仕立てのビーフストロガノフごはん

## 材料
* ・水 … 300cc
* ・トマトジュース … 300cc
* ・ハインツデミグラスソース … 1缶
* ・肉 … 200g
* ・玉ねぎ … 150g
* ・マッシュルーム … 50g
* ・赤みそ … 小さじ1と1/2
* ・塩 … 小さじ2/3
* ・マギーブイヨン … 2袋
* ・じゃがいも … 1こ
* ・油 … 大さじ1
* ・クレソン … 適量
* ・生クリーム … 適量
* ・パセリ … 少々
* ・黒こしょう … 少々

## 手順
1. 下準備 じゃがいもは皮付きのまま1口大で素揚げする。玉ねぎは繊維を断つように細切りにする。
2. ① 鍋に油をひろげ、牛肉を炒める。
3. ② 水、トマトジュース、ハインツデミグラスソース缶をいれて火にかけ沸騰したら弱火にして3分ほどにこむ。
4. ③ みそ、塩、マギーブイヨンをいれて馴染まる。玉ねぎとマッシュルームいれて7分くらい煮る。
5. 土鍋にごはんをいれ、揚げたポテトをのせて上からビーフストロガノフをかける。
6. ④ 生クリームをまわしかけ、黒胡椒、パセリをふって奥にクレソンを飾る。

## メモ
3人前
